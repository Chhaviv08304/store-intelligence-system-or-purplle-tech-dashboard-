# System Design: Store Intelligence System

## 1. Architecture Overview
The Store Intelligence System is designed to process CCTV footage, detect and track individuals, and generate business metrics in real-time. It consists of the following components:

- **Detection & Tracking Module (Python/OpenCV/YOLO):** Reads video frames, performs object detection (people), and uses a tracker (e.g., DeepSORT) to maintain identities across frames. It emits events (e.g., `person_entered`, `person_exited`) via a queue or directly to the backend.
- **Backend API (FastAPI):** Receives event streams, aggregates data, applies funnel logic to calculate metrics, and serves the frontend through REST endpoints (like `/metrics`).
- **Frontend Dashboard (React/Vite):** A live dashboard that polls or receives WebSocket events to display the current store capacity, conversion funnel, and detected anomalies.

## 2. Event Schema
Events generated by the detection pipeline follow this structure:
```json
{
  "event_id": "uuid",
  "timestamp": "2026-06-02T10:00:00Z",
  "event_type": "entry | exit | re_entry | staff_movement",
  "person_id": "tracked_id_123",
  "confidence": 0.95
}
```

## 3. Funnel Logic & Metrics
- **Total Footfall:** Unique persons entering the store.
- **Conversion Rate:** Derived from the total sales transactions (if data provided) divided by total footfall.
- **Dwell Time:** `exit_timestamp` - `entry_timestamp`.
- Double-counting is avoided by maintaining state for each `person_id`.

## 4. Anomaly Detection
Anomalies such as loitering, after-hours movement, or unusual crowd density are flagged by measuring deviations from historical or logical baselines.

## 5. Edge Cases Handled
- **Re-entry:** Handled by a time threshold (e.g., entering again within 5 minutes keeps the same session).
- **Staff Movement:** Staff can be identified by uniform color thresholding or specific zones/patterns, filtering them out of customer footfall.
- **Occlusion:** Robust tracking algorithms (like DeepSORT or ByteTrack) maintain IDs even with brief occlusions.
